Code: режим по умолчанию для всех новых задач. 
В нём агент полностью самостоятелен: он пишет и редактирует код, запускает команды в терминале, проверяет результаты и использует все доступные инструменты для работы с кодовой базой. Подходит для реализации новых функций, рефакторинга, запуска приложений. 
Ключевые возможности:
Полный доступ ко всем инструментам (чтение/запись файлов, выполнение команд, поиск в коде, работа с браузером и т.д.).
Может проверять результаты во встроенном браузере через preview.
Подходит для непосредственной реализации задачи.
 
Ask: строго режим только для чтения. Файлы не правит.
Агент отвечает на вопросы, анализируя релевантный код перед ответом, но не вносит изменений в файлы и не выполняет команды, меняющие состояние рабочего пространства. 
Предназначен для:
Сбора информации о кодовой базе (архитектура, поведение, трейдоффы).
Объяснения кода, изучения концепций.
Исследования незнакомого проекта.
Если пользователь просит что-то реализовать в этом режиме, агент объяснит ограничение и предложит переключиться в Code. 

Plan: режим исключительно для чтения. 
Агент исследует код, задаёт уточняющие вопросы, строит пошаговый план решения задачи и сохраняет его. Он не создаёт, не редактирует, не удаляет и не перемещает файлы. 
Ключевые возможности:
Доступ только для чтения (чтение файлов, поиск, загрузка веб-страниц).
Shell-команды разрешены только в режиме чтения (например, git log, ls).
План считается опубликованным только после вызова специального инструмента update_plan.
После создания плана его можно отредактировать и утвердить, а затем переключиться в режим Code для реализации. Такой подход позволяет контролировать каждый шаг и снижает риск ошибок. 

Debug: специализирован на поиске и исправлении ошибок. 
Агент следует строгому процессу: формулирует 3–5 гипотез о причине проблемы, добавляет целевую инструментацию для их проверки, собирает доказательства из логов и тестов, классифицирует каждую гипотезу (подтверждена/опровергнута/неопределена) и только потом реализует минимальный фикс, подтверждённый доказательствами. 
Не используйте Debug для обычных задач реализации — он предназначен именно для сложных, запутанных ошибок.
