1) Сервис: учебный сервис предварительной оценки заявки на заём под ПТС (carmoney-lab, практикум М3); по README принимает заявку (VIN, год, пробег, оценочная стоимость, сумма, срок), считает LTV и возвращает approve / review / reject, данные синтетические.
2) Makefile: `make up` (docker compose up -d --build), `make down`, `make ps`, `make logs`, `make install` (composer install), `make test` (phpunit локально или в контейнере), `make lint` (php -l по backend/ и tests/), `make seed` (mysql -ulab -plab carmoney_lab < db/seed.sql), `make help`; docker-compose.yml описывает сервисы `backend` (php -S 0.0.0.0:8080 -t backend/public backend/public/router.php, порт 8080, имя из .env.example через ${APP_PORT:-8080}, переменные DB_DSN/DB_USER/DB_PASSWORD/APP_DEBUG, тома backend/frontend/tests) и `db` (mysql:8.0, порт ${DB_PORT:-3307}:3306, init-скрипты db/schema.sql и db/seed.sql, том db-data, healthcheck mysqladmin ping), отдельной команды проверки/запуска не нашёл.
3) Решение approve / review / reject считается в `backend/src/Domain/` (класс DecisionEngine; рядом LtvCalculator, ApplicationValidator, VehicleAge, VinValidator, AssessmentService).
